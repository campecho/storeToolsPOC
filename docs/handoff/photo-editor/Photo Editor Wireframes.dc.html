E · Simple / Standard / Pro — same file, different surface
The suite-wide model: the level changes control density only, never the file. Progressive disclosure, never amputation — Pro is always reachable from Standard.
Simple — the 80% counter job
Crop + Auto-enhance + the three quick fixes. Rail holds Crop and Export only. An associate who learns nothing else still does 80% of the job.
Standard — the default (Section A above)
Full P1 toolset — the six-task rail, contextual panel, undo/redo, compare. What most associates live in.
Pro — for the Elements veterans
Adds levels / curves-lite and numeric entry everywhere. Same panels, denser — no floating palettes, no workspace config. The anti-Elements.

An associate selects a picture on a layout page and needs photo fixes. In both parts the edit is a non-destructive recipe on the placed instance — the original file is untouched, and “Revert photo edits” stays available in the layout's history.
